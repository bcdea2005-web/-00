# رفع أصناف القائمة إلى لوحة التحكم (Sanity)

هذا المجلد يحتوي على **53 صنفاً** جاهزة (بصور وأوصاف وأسعار من التسجيلات) لإدخالها في لوحة تحكم Sanity
الخاصة بالموقع (المشروع `197665fs` / `production`) — تماماً كما لو أُضيفت يدوياً من اللوحة.
الموقع يقرأ الأصناف من Sanity كالمعتاد، ويملأ الأسعار الناقصة ويضيف الأصناف الجديدة من التسجيلات
دون حذف أي صنف قائم في اللوحة.

| الملف | الوظيفة |
|---|---|
| `dishes.ndjson` | الأصناف (سطر JSON لكل طبق) مربوطة بأقسام اللوحة الحالية |
| `images/*.jpg` | صور الأطباق الرئيسية (10 صور، 1280px، ~140KB لكل صورة) |
| `upload.mjs` | سكربت الرفع (يرفع الصور ثم ينشئ الأصناف) |
| `github/sanity-seed.yml` | Workflow لتشغيل السكربت من GitHub بدون تثبيت أي شيء (يُفعَّل بخطوة واحدة — انظر أدناه) |

## الطريقة 1 — من GitHub (بدون تثبيت أي شيء)

0. **فعّل الـ Workflow (مرة واحدة):** لا تستطيع أداة Arena رفع ملفات `.github/workflows` بنفسها، لذلك الملف موجود هنا
   في `sanity-seed/github/sanity-seed.yml`. افتحه على GitHub → اضغط **قلم التعديل** → في خانة اسم الملف
   امسح الاسم واكتب: `../../.github/workflows/sanity-seed.yml` → **Commit changes**.
   (كتابة `../` في خانة الاسم تنقل الملف إلى مجلد أعلى — سينتقل الملف تلقائياً إلى `.github/workflows/`).
1. **أنشئ رمز وصول** من [sanity.io/manage](https://www.sanity.io/manage) → اختر المشروع → **API** → **Tokens** → *Add API token*
   - الاسم: `github-seed` — الصلاحية: **Editor**
   - انسخ الرمز (يظهر مرة واحدة فقط).
2. **أضفه كـ Secret** في المستودع: **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `SANITY_TOKEN` — Secret: الرمز الذي نسخته.
3. افتح تبويب **Actions** → اختر **«رفع أصناف القائمة إلى Sanity»** → **Run workflow**:
   - أول مرة اترك الحقل `preview` لترى المعاينة (لا يكتب شيئاً).
   - ثم شغّله مرة أخرى واكتب `yes` للتنفيذ الفعلي.
4. افتح لوحة التحكم — ستجد الأصناف في أقسامها. **احذف الرمز** من Sanity بعد الانتهاء إن شئت.

## الطريقة 2 — من جهازك

يلزم Node.js 18+ فقط (بدون `npm install`):

```bash
# معاينة
SANITY_TOKEN="<الرمز>" node sanity-seed/upload.mjs

# تنفيذ (ينشئ الأصناف الجديدة فقط)
SANITY_TOKEN="<الرمز>" node sanity-seed/upload.mjs --yes

# تحديث أسعار الأصناف الموجودة دون لمس الوصف أو الصورة
SANITY_TOKEN="<الرمز>" node sanity-seed/upload.mjs --yes --patch-prices
```

## ملاحظات أمان وتكرار

- السكربت **آمن لإعادة التشغيل**: يستخدم `createIfNotExists`، فأي طبق عدّلته لاحقاً من اللوحة
  (سعر، وصف، صورة، إتاحة) **لا يُلمَس**. الصور المرفوعة سابقاً لا تُرفع مرة أخرى.
- `--force` يستبدل الأطباق الموجودة بنسخة الملف — لا تستخدمه إلا إن أردت التراجع عن تعديلاتك.
- الطبق التجريبي الموجود حالياً في اللوحة («كيلوا شية» بسعر 1) **لا يُحذف تلقائياً** — احذفه
  يدوياً من اللوحة بعد الرفع حتى لا يتكرر مع «كيلو شية» الجديد.
- لا يُحذف أي شيء أبداً من هذا السكربت.

## صورة خلفية الواجهة (Landing Page)

الموقع يعرض صورة كبيرة كخلفية للصفحة الرئيسية وفوقها **لون أحمر خفيف**:

- **بدون أي إعداد:** يظهر شعار المطعم كخلفية افتراضية فوق تدرّج أحمر.
- **من لوحة التحكم:** يقرأ الموقع حقل `heroBackground` من مستند `siteSettings` ويعرضه
  كخلفية كبيرة (cover) بدل الشعار.
- **السكربت يضبطها تلقائياً:** عند تشغيل `upload.mjs` يرفع `assets/logo.jpg`
  ويضبطه في `heroBackground` (يمكن تمرير صورة أخرى بـ `--hero <مسار>` أو تخطي الخطوة بـ `--no-hero`).

### إظهار الحقل في لوحتك الحالية المنشورة (mashwi.sanity.studio)

اللوحة المنشورة تُنشر من حسابك في Sanity، لذا إضافة الحقل تتم من كود الـ Studio عندك
بتعديل واحد صغير: افتح الملف الذي يعرّف نوع `siteSettings` (يحتوي `name: 'siteSettings'`)،
وأضف هذا العنصر داخل مصفوفة `fields`، ثم انشر:

```js
{
  name: 'heroBackground',
  title: 'صورة خلفية الواجهة (Landing Page)',
  description: 'صورة كبيرة تُعرض كخلفية للصفحة الرئيسية وفوقها لون أحمر خفيف. اتركها فارغة لعرض شعار المطعم كخلفية.',
  type: 'image',
  options: {hotspot: true},
},
```

```bash
sanity deploy
```

بعد النشر يظهر الحقل في «إعدادات الموقع» — ارفع صورة واحفظ، والموقع يعرضها فوراً
كخلفية كبيرة وفوقها لون أحمر خفيف. ويمكن بدلاً من ذلك تشغيل سكربت الرفع
(Workflow ‏«رفع أصناف القائمة إلى Sanity» بكتابة yes) ليضبط شعار المطعم كخلفية
افتراضية تلقائياً؛ عادةً يقبل Sanity كتابة الحقل عبر API حتى قبل إضافته للمخطط،
وإن رفضها فسيسجّل السكربت رسالة خطأ واضحة — عندها أضِف الحقل للمخطط أولاً ثم أعد التشغيل.

> بديل كامل: مجلد `studio/` في هذا المستودع يحتوي لوحة تحكم جاهزة بنفس الحقل وكل
> الأنواع — إن أردت إعادة بناء اللوحة من الصفر اتبع `studio/README.md`.

```js
{
  name: 'heroBackground',
  title: 'صورة خلفية الواجهة (Landing Page)',
  description: 'صورة كبيرة تُعرض كخلفية للصفحة الرئيسية وفوقها لون أحمر خفيف. اتركها فارغة لعرض شعار المطعم كخلفية.',
  type: 'image',
  options: { hotspot: true },
},
```

بعد النشر ستجد الحقل في اللوحة تحت إعدادات الموقع: ارفع أي صورة واحفظ — تتحدّث الواجهة فوراً.
لمسح الصورة والعودة لشعار المطعم كخلفية: احذف قيمة الحقل واحفظ.

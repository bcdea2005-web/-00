# 🍔 المنيو الإلكتروني — بوكس سوسة (BOX SOUSSE)

موقع قائمة إلكترونية عصري لمطعم فاست فود في سوسة، بألوان حمراء وصفراء جذابة،
مع عروض اليوم، سلة طلبات، بحث وتصنيفات، وطلب مباشر عبر **واتساب**.

## 📂 المحتوى

| ملف / مجلد | الوصف |
|---|---|
| `index.html` | الموقع كاملاً (HTML + CSS + JavaScript في ملف واحد) |
| `img/` | صور الأصناف (برجر، تاكوس، بوكسات، بيتزا...) |

## ✏️ كيف تعدّل البيانات؟

كل شيء في أعلى قسم `<script>` داخل `index.html`:

```js
var SITE = {
  name: 'بوكس سوسة',
  phone: '+21622000000',   // ← غيّر رقم الهاتف / واتساب الحقيقي
  currency: 'د.ت',
  address: 'شارع الجمهورية — وسط المدينة، سوسة، تونس'
};
```

- **إضافة صنف**: أضف سطراً في مصفوفة `MENU` بنفس شكل الأصناف الموجودة.
`cat` يجب أن يكون أحد: `boxes / burger / tacos / pizza / sides / dessert / drinks`
- **تعديل عرض**: عدّل عناصر مصفوفة `OFFERS`.
- **تغيير صورة**: ضع الصورة داخل `img/` ثم غيّر المسار في `IMG`.

## 🚀 التشغيل

```bash
cd box-sousse
python3 -m http.server 8000
# افتح http://localhost:8000
```
